# Security

## Reporting a vulnerability

Report security issues through GitHub private vulnerability reporting:

https://github.com/huhugyto177-hub/bg-digital-twin/security/advisories/new

Please do not open a public issue for a suspected vulnerability, and do not send reports to a personal email address.

This repository is a research simulator. It does not ship accounts, credentials, or a hosted database. A report is still useful when it describes a way to execute untrusted input unexpectedly, to leak data a user pasted into a local run, or to make the app misrepresent a non-claim as a prediction.

Include the version you ran (`src.__version__` and the commit), the operating system, and a minimal way to reproduce the issue.
